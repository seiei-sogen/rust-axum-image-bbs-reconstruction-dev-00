## タスク概要

Rust + axum 0.7 プロジェクトの土台を作成し、`cargo run` で http://localhost:3000 にアクセスすると "Hello, axum!" が返るところまでを構築する。Zenn 記事第1回として「環境構築〜Hello, world」を切り出せる粒度に揃える。 🔵

## 完了条件

- 🔵 `cargo new rust-axum-image-bbs --bin` 相当でプロジェクト雛形が出来ている
- 🔵 `Cargo.toml` に `axum = "0.7"` と `tokio = { version = "1", features = ["full"] }` が追加されている
- 🔵 `cargo run` がエラーなく成功する
- 🔵 `curl http://localhost:3000/` で `Hello, axum!` が返る
- 🔵 `.gitignore` に `/target`, `/data`, `/uploads`, `.env`, `*.db*` が含まれている
- 🔵 `Cargo.lock` が git 管理対象に入っている（アプリのため）
- 🔵 `src/main.rs` に「axum サーバを起動する」旨の日本語ドキュメンテーションコメントが付与されている

## 実装詳細

### Cargo.toml の依存追加 🔵
- `axum = "0.7"`
- `tokio = { version = "1", features = ["full"] }`
- `[package] edition = "2021"`、`name = "rust-axum-image-bbs"`

### src/main.rs の構造 🔵
- `#[tokio::main]` の `async fn main()`
- `axum::Router::new().route("/", get(root_handler))`
- `tokio::net::TcpListener::bind("0.0.0.0:3000").await?`
- `axum::serve(listener, app).await?`
- `async fn root_handler() -> &'static str { "Hello, axum!" }`

### ディレクトリ準備 🟡
- `data/.gitkeep`、`uploads/.gitkeep` を作成し、後続フェーズで使うフォルダを確保

### .gitignore 🔵
- `/target/`、`/data/*`（`!.gitkeep`）、`/uploads/*`（`!.gitkeep`）、`.env`、`*.db`、`*.db-journal`、`*.db-wal`、`*.db-shm`

## 実装手順（DIRECT タイプ）

1. `/tumigi:direct-setup` を実行
   - `cargo new` 相当の初期化
   - `Cargo.toml` 編集
   - `src/main.rs` 記述
   - `.gitignore` 整備
2. `/tumigi:direct-verify` を実行
   - `cargo build` でコンパイルエラーがないこと
   - `cargo run` で起動し `curl http://localhost:3000/` を確認
   - レスポンスが `Hello, axum!` であることを確認

## 注意事項

- 🟡 axum 0.6 系の記事を参考にすると `axum::Server::bind` を使う書き方が出てくるが、本プロジェクトでは 0.7 系の `axum::serve` を使う（破壊的変更があるため）
- 🔵 ポートはまずハードコードでよい（環境変数化は TASK-0004 で行う）
- 🟡 Windows + WSL の場合、`0.0.0.0:3000` でバインドしないとホスト側からアクセスできないことがある
