## 実装詳細

### src/models/image_ext.rs 🔵
```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum ImageExt { Jpg, Gif, Png }

impl ImageExt {
    pub fn as_str(self) -> &'static str {
        match self { Self::Jpg => "jpg", Self::Gif => "gif", Self::Png => "png" }
    }
    pub fn from_mime(mime: &str) -> Option<Self> {
        match mime {
            "image/jpeg" => Some(Self::Jpg),
            "image/gif" => Some(Self::Gif),
            "image/png" => Some(Self::Png),
            _ => None,
        }
    }
}
```

### src/validators/post_form.rs 🔵
```rust
pub struct PostFormInput {
    pub title: String,
    pub text: String,
    pub image_bytes: Option<Vec<u8>>,
    pub image_filename: Option<String>,
    pub delete_image: bool,
}

pub struct ValidatedImage { pub bytes: Vec<u8>, pub extension: ImageExt }
pub struct ValidatedPostForm { pub title: String, pub text: String, pub image: Option<ValidatedImage>, pub delete_image: bool }

pub fn validate(input: &PostFormInput, config: &AppConfig) -> Result<ValidatedPostForm, Vec<String>> {
    let mut errors = Vec::new();
    let title = input.title.trim();
    let title_len = title.chars().count();
    if title_len == 0 { errors.push("タイトルは必須です".into()); }
    else if title_len > 50 { errors.push("タイトルは50文字以内で入力してください".into()); }

    let text_len = input.text.chars().count();
    if text_len > 500 { errors.push("本文は500文字以内で入力してください".into()); }

    let image = match &input.image_bytes {
        None => None,
        Some(bytes) if bytes.is_empty() => None,
        Some(bytes) => {
            if bytes.len() > config.max_image_bytes {
                errors.push("画像サイズは5MB以内にしてください".into());
                None
            } else {
                match infer::get(bytes).map(|t| t.mime_type()) {
                    Some(mime) if config.allowed_mime.contains(&mime) => {
                        ImageExt::from_mime(mime).map(|ext| ValidatedImage { bytes: bytes.clone(), extension: ext })
                    }
                    _ => {
                        errors.push("対応していない画像形式です (jpg/gif/png)".into());
                        None
                    }
                }
            }
        }
    };

    if errors.is_empty() {
        Ok(ValidatedPostForm { title: title.to_string(), text: input.text.clone(), image, delete_image: input.delete_image })
    } else {
        Err(errors)
    }
}
```

## Zenn 記事ドラフト

### 記事タイトル案
- 「Rust + axum で画像掲示板を作る (9) - infer クレートで画像 MIME を検証する」

### 想定見出し（H2）
1. なぜサーバ側で MIME を判定するのか（拡張子・Content-Type は信用しない）
2. `infer` クレートのマジックナンバー判定
3. `ImageExt` enum でファイル名生成を安全化
4. バリデーション結果は `Vec<String>` でまとめる
5. `chars().count()` と `len()` の違いを学ぶ

### 伝える主なポイント
- HTTP ヘッダの `Content-Type` は容易に偽装可能なため、サーバで再判定する
- 拡張子をユーザー入力から取らずに `ImageExt::as_str()` で固定文字列に変える（パストラバーサル防止）
- Rust の `String::len()` はバイト数、文字数は `chars().count()`
- バリデーションエラーは複数まとめて返したほうが UX が良い

## 注意事項

- 🔵 マルチバイト文字を含む title の長さは `chars().count()` で UTF-8 コードポイント数を測ること（バイト数ではない）
- 🟡 trim 後の文字数で判定する。前後空白だけの title は空扱いとする
- 🔵 `infer::get()` は `Option<infer::Type>` を返す。`bytes` が短すぎる場合 `None` になり得るのでハンドリングが必要
