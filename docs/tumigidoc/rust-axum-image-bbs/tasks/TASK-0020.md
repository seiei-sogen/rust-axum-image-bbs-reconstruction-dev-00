## タスク概要

`tracing-subscriber` を `EnvFilter::from_default_env()` ベースに切り替え、環境変数 `LOG_FORMAT=json` のときに JSON 形式で出力できるようにする。投稿作成・編集・削除の主要ハンドラに `#[tracing::instrument]` を付与し、リクエスト span にパラメータが乗るようにする。最後に `README.md` を整備し、Zenn 記事との対応表まで含めて「初見の開発者がそのまま動かせる」状態にして本プロジェクトを完成させる。 🔵

## 実装詳細

### tracing 初期化（main.rs 抜粋）🔵
```rust
use tracing_subscriber::EnvFilter;

fn init_tracing() {
    let filter = EnvFilter::try_from_default_env()
        .unwrap_or_else(|_| EnvFilter::new("info"));
    if std::env::var("LOG_FORMAT").as_deref() == Ok("json") {
        tracing_subscriber::fmt()
            .json()
            .with_env_filter(filter)
            .init();
    } else {
        tracing_subscriber::fmt()
            .with_env_filter(filter)
            .init();
    }
}
```

### ハンドラへの instrument 付与 🔵
```rust
#[tracing::instrument(skip(state, multipart), fields(post_id = tracing::field::Empty))]
pub async fn create(State(state): State<AppState>, multipart: Multipart) -> AppResult<Response> {
    // ... INSERT 後に
    tracing::Span::current().record("post_id", new_id);
    // ...
}
```
