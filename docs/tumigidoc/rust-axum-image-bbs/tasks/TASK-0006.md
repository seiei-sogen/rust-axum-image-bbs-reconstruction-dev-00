## タスク概要

`askama 0.12` + `askama_axum 0.4` を導入し、`templates/base.html`（共通レイアウト + Bootstrap CDN）と `templates/index.html`（`extends "base.html"`、投稿フォーム + 一覧プレースホルダ）の雛形を作る。`src/templates/mod.rs` に `IndexTemplate` 構造体を定義し、`GET /` で空ページを描画できる状態にする。 🔵

## 依存タスク

- TASK-0004（AppState 配線済み Router がある）

## 完了条件

- 🔵 `Cargo.toml` に `askama = "0.12"` と `askama_axum = "0.4"` が追加されている
- 🔵 `templates/base.html` が存在し、`<!doctype html>`・`<title>{% block title %}画像掲示板{% endblock %}</title>`・Bootstrap 5 CDN リンク・`{% block content %}{% endblock %}` を含む
- 🔵 `templates/index.html` が存在し、`{% extends "base.html" %}` + `{% block content %}` 内に投稿フォーム HTML + 一覧プレースホルダがある
- 🔵 `src/templates/mod.rs` に `#[derive(Template)] #[template(path = "index.html")] pub struct IndexTemplate { ... }` が定義
- 🔵 `GET /` ハンドラが `IndexTemplate { ... }.into_response()`（askama_axum 経由）で 200 を返す
- 🔵 ブラウザで http://localhost:3000/ にアクセスすると Bootstrap が適用された空のページが見える
- 🔵 Askama の自動エスケープが有効（デフォルトで `escape="html"`）

## Zenn 記事ドラフト

### 記事タイトル案
- 「Rust + axum で画像掲示板を作る (6) - Askama でテンプレートを書く」

### 想定見出し（H2）
1. なぜ Askama を選ぶか（コンパイル時テンプレ）
2. `base.html` + `extends` の継承構造
3. `IndexTemplate` 構造体と `#[template(path = ...)]`
4. `askama_axum` で `IntoResponse` を実装する
5. Bootstrap CDN を貼って雰囲気を整える

### 伝える主なポイント
- Askama はコンパイル時にテンプレを Rust コードに展開する → ランタイム解析コストゼロ
- フィールド名がテンプレ内変数と一致する必要がある（後続タスクで `posts` を追加）
- 自動 HTML エスケープがデフォルトで有効（XSS 防止）
- `askama_axum` を入れると `Response` への変換が `impl IntoResponse` で済む

### コード例として載せる断片
- `templates/base.html` の `block` 部分
- `templates/index.html` の `extends` 行と form
- `IndexTemplate` 構造体定義
- `root_handler` の戻り型変更
