## タスク概要

multi-stage `Dockerfile` と `docker-compose.yml` を作成し、`docker compose up --build` だけでアプリが起動できるようにする。ビルドステージは `rust:1.75-slim`、ランタイムステージは `debian:bookworm-slim` を採用し、`ca-certificates` のみ追加して軽量に保つ。compose ではホストの `./data` `./uploads` を bind mount し、コンテナ再起動後もデータが永続するようにする。 🔵

## 完了条件

- 🔵 リポジトリ直下に `Dockerfile`, `docker-compose.yml`, `.dockerignore` が存在する
- 🔵 `Dockerfile` は2ステージ構成（builder / runtime）で、最終イメージサイズが極端に大きくない（数百MB以内）
- 🔵 ビルドステージで `cargo build --release` が走り、`/app/target/release/rust_axum_image_bbs`（バイナリ名は Cargo.toml に合わせる）が生成
- 🔵 ランタイムステージに `migrations/`, `templates/`, バイナリのみコピー
- 🔵 `EXPOSE 3000` と `CMD ["./rust_axum_image_bbs"]`（または fully-qualified パス）が設定
- 🔵 `docker-compose.yml` の `services.app` が `build: .`, `ports: ["3000:3000"]`, `volumes: ["./data:/app/data", "./uploads:/app/uploads"]`, `environment` を指定
- 🔵 環境変数 `DATABASE_URL=sqlite:///app/data/app.db`, `UPLOAD_DIR=/app/uploads`, `PORT=3000`, `RUST_LOG=info` が compose で渡る
- 🔵 `.dockerignore` に `target/`, `.git/`, `.env`, `data/`, `uploads/`, `*.md` などを記載
- 🔵 `docker compose up --build` で起動し、ホストブラウザから `http://localhost:3000` で一覧画面が表示される
- 🔵 `docker compose down` → `docker compose up` でも投稿データ・画像が残っていることを確認
- 🟡 ビルド依存（`pkg-config`, `libssl-dev` 等）が必要なら builder にだけ入れる

## 実装詳細

### Dockerfile 🔵
```dockerfile
# syntax=docker/dockerfile:1.6
FROM rust:1.75-slim AS builder
WORKDIR /app
RUN apt-get update && apt-get install -y --no-install-recommends pkg-config libssl-dev \
    && rm -rf /var/lib/apt/lists/*
COPY Cargo.toml Cargo.lock ./
COPY migrations ./migrations
COPY src ./src
COPY templates ./templates
ENV SQLX_OFFLINE=true
RUN cargo build --release

FROM debian:bookworm-slim AS runtime
WORKDIR /app
RUN apt-get update && apt-get install -y --no-install-recommends ca-certificates \
    && rm -rf /var/lib/apt/lists/*
COPY --from=builder /app/target/release/rust_axum_image_bbs ./rust_axum_image_bbs
COPY --from=builder /app/migrations ./migrations
COPY --from=builder /app/templates ./templates
RUN mkdir -p /app/data /app/uploads
EXPOSE 3000
CMD ["./rust_axum_image_bbs"]
```

### docker-compose.yml 🔵
```yaml
services:
  app:
    build: .
    ports:
      - "3000:3000"
    volumes:
      - ./data:/app/data
      - ./uploads:/app/uploads
    environment:
      DATABASE_URL: sqlite:///app/data/app.db
      UPLOAD_DIR: /app/uploads
      PORT: "3000"
      RUST_LOG: info
    restart: unless-stopped
```

### .dockerignore 🔵
```
target/
.git/
.gitignore
.env
data/
uploads/
*.md
docs/
tests/
.github/
```

### SQLX_OFFLINE モードのメモ 🟡
- `cargo sqlx prepare` 済みの `sqlx-data.json`（または `.sqlx/`）を commit しておく
- それが無い場合は `ENV SQLX_OFFLINE=false` + ビルド時 DB アクセス、または `query!` を使わず動的クエリで回避
