## タスク概要

アプリ全体で共有する設定 `AppConfig` と状態 `AppState`（DB プール・アップロード先・設定）を作り、`Router::with_state(state)` で配線する。`dotenvy` で `.env` を読み込み、PORT / DATABASE_URL / UPLOAD_DIR を環境変数から切り替えられるようにする。さらに `DefaultBodyLimit::max(5 * 1024 * 1024)` を Router に装着し 5MB 上限を準備する。 🔵

## 実装詳細

### src/config.rs 🔵
```rust
//! アプリ全体の設定値。環境変数 or デフォルトで初期化する。
#[derive(Debug, Clone)]
pub struct AppConfig {
    pub page_size: u32,
    pub max_image_bytes: usize,
    pub allowed_mime: &'static [&'static str],
}

impl AppConfig {
    pub fn from_env_or_default() -> Self {
        Self {
            page_size: 20,
            max_image_bytes: 5 * 1024 * 1024,
            allowed_mime: &["image/jpeg", "image/gif", "image/png"],
        }
    }
}
```

### src/state.rs 🔵
```rust
//! axum の State Extractor で共有する状態。Clone は内部で Arc が回るので安価。
use std::path::PathBuf;
use sqlx::SqlitePool;
use crate::config::AppConfig;

#[derive(Clone)]
pub struct AppState {
    pub db: SqlitePool,
    pub upload_dir: PathBuf,
    pub config: AppConfig,
}
```

### src/main.rs 🔵
- `dotenvy::dotenv().ok();` を tracing 初期化前に呼ぶ
- `let port: u16 = std::env::var("PORT").ok().and_then(|s| s.parse().ok()).unwrap_or(3000);`
- `let upload_dir = PathBuf::from(std::env::var("UPLOAD_DIR").unwrap_or_else(|_| "uploads".to_string()));`
- `let state = AppState { db: pool, upload_dir, config: AppConfig::from_env_or_default() };`
- `let app = Router::new().route("/", get(root_handler)).layer(DefaultBodyLimit::max(5 * 1024 * 1024)).layer(TraceLayer::new_for_http()).with_state(state);`

### src/main.rs の mod 宣言 🔵
- `mod config;`
- `mod state;`

### 記事タイトル案
- 「Rust + axum で画像掲示板を作る (4) - AppState と環境変数で設定を統一する」

### 想定見出し（H2）
1. `axum::extract::State` の役割と Clone の重要性
2. `AppState` と `AppConfig` の責務を分ける
3. `dotenvy` で `.env` を読み込むタイミング
4. `DefaultBodyLimit` で DoS 対策の入口を作る
5. `Router::with_state()` で配線する

### 伝える主なポイント
- axum 0.7 の `State<T>` は `T: Clone` を要求する → `Arc<Inner>` を内包する Clone 設計
- 設定（不変）と状態（可変・接続を保持）を型として分ける利点
- `DefaultBodyLimit::max(N)` を入れないとデフォルトは 2MB（axum 0.7）であるため、5MB を意識的に上書きする
- 環境変数のフォールバックパターン（`std::env::var().ok().and_then(...).unwrap_or(default)`）

## 注意事項

- 🔵 axum 0.7 のデフォルト `DefaultBodyLimit` は 2MB なので、画像投稿には必ず上書きが必要（EDGE-001）
- 🔵 `Router::with_state()` の戻り型は `Router<()>` に変わり、以後 `Router::new()` のジェネリクスが噛み合わなくなる場合があるので、Router 構築の最後で `.with_state()` を呼ぶこと
- 🟡 `dotenvy::dotenv().ok()` のエラー無視は学習用途として許容。本番運用なら `.expect(".env not found")` も検討
- 🔵 関連要件: NFR-403（環境変数）、EDGE-001（5MB 上限）
