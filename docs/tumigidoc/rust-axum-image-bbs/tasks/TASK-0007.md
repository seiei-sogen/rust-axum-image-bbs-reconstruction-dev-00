## タスク概要

`GET /` のハンドラ `handlers::posts::list` を実装し、`PostRepo::list` + `count` を呼び出して `IndexTemplate` に投稿リスト・件数・ページ情報を渡して描画する。テンプレ側で画像（あれば）・タイトル・本文・投稿日時を表示し、0件時には「投稿がまだありません」を表示する。 🔵

## 実装詳細

### src/handlers/mod.rs 🔵
```rust
pub mod posts;
```

### src/handlers/posts.rs 🔵
```rust
use axum::{extract::State, response::IntoResponse};
use crate::{state::AppState, repository::post_repo, templates::IndexTemplate, errors::AppResult};

pub async fn list(State(state): State<AppState>) -> AppResult<impl IntoResponse> {
    let posts = post_repo::list(&state.db, state.config.page_size, 0).await?;
    let total = post_repo::count(&state.db).await?;
    let total_pages = ((total as f32) / (state.config.page_size as f32)).ceil() as u32;
    Ok(IndexTemplate { posts, page: 1, total_pages: total_pages.max(1) })
}
```

注: TASK-0012 で `AppError` を導入するまで暫定的に `anyhow::Result` などで凌ぐ可能性あり 🟡

- `Vec<Post>` をテンプレに渡すだけで `for` ループが書ける
- `{% match %}{% when Some with (x) %}` という Askama 独自構文
- 旧PHP では `while ($row = mysqli_fetch_assoc(...))` だったが、Rust だと値ベースで安全
