## タスク概要

`POST /posts/:id/edit` のハンドラ `handlers::posts::edit_submit` を実装する。`Multipart` から title / text / (image) / (delete_image) を取得、`PostRepo::find(id)` で 404 確認、`validate` を通した上で更新する。新画像なし → image 列は不変。新画像あり → 旧画像（旧拡張子）を `storage::delete_image` で削除し、新画像を `storage::save_image(id)` で保存して `PostRepo::update_image_path` で更新。`update_date` を更新し、成功時は 303 で `/` にリダイレクト。バリデーションエラー時は `EditTemplate { post, form, errors }` を 400 で再描画（入力値保持）。**`delete_image=on` の単独処理は TASK-0015 で追加するため、本タスクでは扱わない**。 🔵

## 実装詳細

### handlers::posts::edit_submit 🔵
```rust
pub async fn edit_submit(
    State(state): State<AppState>,
    Path(id): Path<i64>,
    mut multipart: Multipart,
) -> AppResult<Response> {
    let post = post_repo::find(&state.db, id).await?.ok_or(AppError::NotFound)?;
    let input = parse_multipart(&mut multipart).await?;
    let validated = match validators::post_form::validate(&input, &state.config) {
        Ok(v) => v,
        Err(errors) => {
            return Ok((StatusCode::BAD_REQUEST, EditTemplate {
                post, form: input, errors,
            }).into_response());
        }
    };

    // title/text は常に更新
    post_repo::update(&state.db, id, &validated.title, &validated.text).await?;

    // 新画像あり → 旧画像削除 + 新画像保存 + image 列更新
    if let Some(image) = validated.image.as_ref() {
        image_store::delete_image(&state.upload_dir, id).await?;
        let new_path = image_store::save_image(&state.upload_dir, id, image).await?;
        post_repo::update_image_path(&state.db, id, Some(new_path)).await?;
    }
    // TODO(TASK-0015): delete_image=on 単独ケースの処理を追加

    Ok(Redirect::to("/").into_response())
}
```

### PostRepo 追加メソッド 🔵
```rust
pub async fn update(db: &SqlitePool, id: i64, title: &str, text: &str) -> AppResult<()> {
    sqlx::query!(
        "UPDATE post SET title = ?, text = ?, update_date = datetime('now') WHERE id = ?",
        title, text, id
    ).execute(db).await?;
    Ok(())
}

pub async fn update_image_path(db: &SqlitePool, id: i64, image: Option<String>) -> AppResult<()> {
    sqlx::query!(
        "UPDATE post SET image = ?, update_date = datetime('now') WHERE id = ?",
        image, id
    ).execute(db).await?;
    Ok(())
}
```
