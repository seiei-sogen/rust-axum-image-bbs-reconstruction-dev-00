## タスク概要

`src/storage/image_store.rs` に `save_image` / `delete_image` を実装し、`tower-http::services::ServeDir` を `/uploads` にマウントして画像配信を可能にする。`create` ハンドラを「INSERT → save_image(id) → UPDATE image=path」に拡張し、save_image 失敗時は `DELETE FROM post WHERE id = ?` でロールバックする。`tokio::fs` の async I/O を使う。 🔵

## 実装詳細

### src/storage/image_store.rs 🔵
```rust
use std::path::Path;
use crate::validators::post_form::ValidatedImage;
use crate::errors::{AppResult, AppError};

pub async fn save_image(upload_dir: &Path, id: i64, image: &ValidatedImage) -> AppResult<String> {
    tokio::fs::create_dir_all(upload_dir).await?;
    let filename = format!("{id}.{}", image.extension.as_str());
    let path = upload_dir.join(&filename);
    tokio::fs::write(&path, &image.bytes).await?;
    Ok(filename)
}

pub async fn delete_image(upload_dir: &Path, id: i64) -> AppResult<()> {
    for ext in ["jpg", "gif", "png"] {
        let path = upload_dir.join(format!("{id}.{ext}"));
        match tokio::fs::remove_file(&path).await {
            Ok(_) => {}
            Err(e) if e.kind() == std::io::ErrorKind::NotFound => {}
            Err(e) => return Err(AppError::Io(e)),
        }
    }
    Ok(())
}
```

### handlers::posts::create のロールバック対応 🔵
```rust
// INSERT して id を得る
let row = sqlx::query!("INSERT INTO post(title, text) VALUES (?, ?)", validated.title, validated.text)
    .execute(&state.db).await?;
let new_id = row.last_insert_rowid();

// 画像があれば保存 → UPDATE / 失敗時 DELETE でロールバック
if let Some(image) = validated.image.as_ref() {
    match image_store::save_image(&state.upload_dir, new_id, image).await {
        Ok(path) => {
            sqlx::query!("UPDATE post SET image = ?, update_date = datetime('now') WHERE id = ?",
                path, new_id).execute(&state.db).await?;
        }
        Err(e) => {
            tracing::warn!(post_id = new_id, error = ?e, "save_image failed, rolling back insert");
            let _ = sqlx::query!("DELETE FROM post WHERE id = ?", new_id).execute(&state.db).await;
            return Err(e);
        }
    }
}
```
