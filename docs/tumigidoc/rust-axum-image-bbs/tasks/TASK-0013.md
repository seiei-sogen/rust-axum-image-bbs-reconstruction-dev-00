## タスク概要

`GET /posts/:id/edit` のハンドラ `handlers::posts::edit_form` を実装する。`Path<i64>` で id を抽出し、`PostRepo::find(id)` で取得、`None` の場合は `AppError::NotFound`（404）を返す。`templates/edit.html` を新規作成（`extends base.html`）して既存値で初期表示し、`image` はプレビュー表示、画像削除チェックボックスを設置する（実処理は TASK-0015）。`src/templates/mod.rs` に `EditTemplate` を追加。 🔵

## 依存タスク

- TASK-0012（AppError + IntoResponse でエラー応答が一本化済み）

## 完了条件

- 🔵 `handlers::posts::edit_form(State<AppState>, Path<i64>) -> AppResult<impl IntoResponse>` が実装され、Router に `.route("/posts/:id/edit", get(edit_form))` が追加
- 🔵 `PostRepo::find(&db, id).await?` が `Some(post)` を返す場合 `EditTemplate { post, errors: vec![], form: PostFormInput::from(&post) }` を 200 で返す

- 🔵 「登録」ボタンの onclick で `confirm("登録します。よろしいですか？")` を呼ぶ（送信処理は TASK-0014）
- 🔵 cargo test で「存在する id → 200 + 既存値レンダリング」「存在しない id → AppError::NotFound 経由で 404」のテストがグリーン
- 🟡 画像削除チェックボックスは UI のみ。実処理は TASK-0015 で実装

## 実装詳細

### handlers::posts::edit_form 🔵
```rust
pub async fn edit_form(
    State(state): State<AppState>,
    Path(id): Path<i64>,
) -> AppResult<impl IntoResponse> {
    let post = post_repo::find(&state.db, id).await?.ok_or(AppError::NotFound)?;
    let form = PostFormInput {
        title: post.title.clone(),
        text: post.text.clone(),
        image_bytes: None,
        image_filename: None,
        delete_image: false,
    };
    Ok(EditTemplate { post, form, errors: vec![] })
}
```

### EditTemplate 🔵
- `src/templates/mod.rs` に追加:
```rust
#[derive(Template)]
#[template(path = "edit.html")]
pub struct EditTemplate {
    pub post: Post,
    pub form: PostFormInput,
    pub errors: Vec<String>,
}
```

### templates/edit.html 🔵
- `{% extends "base.html" %}` で共通レイアウト継承
- フォーム: `<form method="post" action="/posts/{{ post.id }}/edit" enctype="multipart/form-data">`
- title: `<input name="title" value="{{ form.title }}">`
- text: `<textarea name="text">{{ form.text }}</textarea>`
- 既存画像があれば `{% if let Some(img) = post.image %}<img src="/uploads/{{ img }}" class="img-fluid">{% endif %}`
- 画像差し替え: `<input type="file" name="image" accept="image/jpeg,image/png,image/gif">`
- 画像削除: `<label><input type="checkbox" name="delete_image" value="on"> 画像を削除</label>`
- エラー: `{% if !errors.is_empty() %}<div class="alert alert-danger">...</div>{% endif %}`
- 登録ボタン: `<button type="submit" onclick="return confirm('登録します。よろしいですか？');" class="btn btn-primary">登録</button>`
- 戻る: `<a href="/" class="btn btn-secondary">戻る</a>`
