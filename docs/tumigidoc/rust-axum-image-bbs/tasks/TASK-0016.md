## タスク概要

`POST /posts/:id/delete` のハンドラ `handlers::posts::delete` を実装する。`Path<i64>` で id 抽出、`PostRepo::find(id)` で 404 確認、post が image を持っていれば `storage::delete_image` でファイル削除（失敗は警告ログで処理続行）、`PostRepo::delete(id)` で DB レコード削除、303 で `/` にリダイレクト。一覧テンプレ `index.html` に各行の「編集」「削除」ボタンを追加し、JS `msgDelete(id)` 関数で `if(confirm(...)) { form.submit(); }` を実装。GET メソッドはルート定義しないことで axum 標準の 405 が返る（NFR-105: 旧 PHP からの改善点）。 🔵

## 実装詳細

### handlers::posts::delete 🔵
```rust
pub async fn delete(
    State(state): State<AppState>,
    Path(id): Path<i64>,
) -> AppResult<Response> {
    let post = post_repo::find(&state.db, id).await?.ok_or(AppError::NotFound)?;

    // 画像があれば物理ファイル削除（失敗は警告のみで処理続行）
    if post.image.is_some() {
        if let Err(e) = image_store::delete_image(&state.upload_dir, id).await {
            tracing::warn!(post_id = id, error = ?e, "image delete failed, continuing with DB delete");
        }
    }

    post_repo::delete(&state.db, id).await?;
    Ok(Redirect::to("/").into_response())
}
```

### PostRepo::delete 🔵
```rust
pub async fn delete(db: &SqlitePool, id: i64) -> AppResult<()> {
    sqlx::query!("DELETE FROM post WHERE id = ?", id).execute(db).await?;
    Ok(())
}
```

### Router 🔵
- `.route("/posts/:id/delete", post(handlers::posts::delete))`

  }

## 単体テスト要件（TDD 観点）

- 🔵 `delete_removes_post_and_image`: 画像付き post を 1 件作って delete → DB に該当 id なし、ファイルも消えている
- 🔵 `delete_handles_post_without_image`: 画像なし post → DB から削除されるだけで OK
- 🔵 `delete_returns_not_found_for_missing_id`: 存在しない id → `AppError::NotFound`
- 🔵 `delete_continues_when_image_delete_fails`: image_store::delete_image を mock で失敗 → DB レコードは削除される、warn ログが出る
- 🟡 `image_store::delete_image_is_idempotent`: 既に削除済みのファイルへの delete_image → エラーにならない（TASK-0011 のテストでカバー済みの場合は省略）
