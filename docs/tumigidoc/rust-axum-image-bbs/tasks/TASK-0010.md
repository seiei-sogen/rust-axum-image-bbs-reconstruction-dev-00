## タスク概要

`POST /posts` のハンドラ `handlers::posts::create` を実装する。`Multipart` extractor で title / text / image / delete_image を取り出し、`validate` を経由した上で INSERT する。**画像保存は本タスクでは扱わず、TASK-0011 で追加する**。バリデーションエラー時は `IndexTemplate` を `errors` 入りで再描画し、入力値を保持する（PRG パターン、303 リダイレクト）。 🔵

## 実装詳細

### handlers::posts::create 🔵
```rust
pub async fn create(
    State(state): State<AppState>,
    mut multipart: Multipart,
) -> AppResult<Response> {
    let input = parse_multipart(&mut multipart).await?;
    let validated = match validators::post_form::validate(&input, &state.config) {
        Ok(v) => v,
        Err(errors) => {
            let posts = post_repo::list(&state.db, state.config.page_size, 0).await?;
            let total = post_repo::count(&state.db).await?;
            let total_pages = ((total + state.config.page_size - 1) / state.config.page_size).max(1);
            return Ok((StatusCode::BAD_REQUEST, IndexTemplate {
                posts, page: 1, total_pages, errors, form: input,
            }).into_response());
        }
    };

    sqlx::query!(
        "INSERT INTO post (title, text) VALUES (?, ?)",
        validated.title, validated.text
    ).execute(&state.db).await?;

    Ok(Redirect::to("/").into_response())
}
```

### parse_multipart ヘルパ 🔵
- `while let Some(field) = multipart.next_field().await?`
- `field.name()` で `title` / `text` / `image` / `delete_image` を振り分け
- `image` フィールドは `field.bytes().await?` を `image_bytes` に格納
- `image_filename` は `field.file_name().map(String::from)`

### IndexTemplate / index.html 拡張 🔵
- フィールド追加: `errors: Vec<String>`、`form: PostFormInput`
- index.html 冒頭で `{% if !errors.is_empty() %}<div class="alert alert-danger"><ul>{% for e in errors %}<li>{{ e }}</li>{% endfor %}</ul></div>{% endif %}`
- input に `value="{{ form.title }}"` / textarea に `{{ form.text }}` を埋め込む

### Router 追加 🔵
- `.route("/posts", post(handlers::posts::create))`

## 注意事項

- 🔵 axum の `Multipart` は1度走査すると消費される → エラー時の再描画では再パースしない
- 🔵 `Redirect::to("/")` はデフォルトで 303
- 🟡 画像 bytes をメモリに全部読むので、5MB の上限（DefaultBodyLimit）は必須
- 🔵 関連要件: REQ-003（フォーム受信）、REQ-004（INSERT）、REQ-201（バリデーション + 入力値保持）、REQ-202（成功メッセージ・リダイレクト）
