## タスク概要

`PaginationQuery { page: u32 }` extractor を導入し、`?page=N` を受けて `limit = page_size`、`offset = (page-1) * page_size` を計算する。`total_pages = ceil(total / page_size)` を求め、テンプレ側に「前へ / N / 次へ」を出す。負値や不正な値は 1 にフォールバックする。 🔵

## 実装詳細

### src/handlers/pagination.rs 🔵
```rust
//! `?page=N` を受け取り、最低1にフォールバックする extractor。
use serde::Deserialize;

#[derive(Debug, Deserialize)]
pub struct PaginationQuery {
    #[serde(default = "default_page")]
    pub page: u32,
}

fn default_page() -> u32 { 1 }

impl PaginationQuery {
    pub fn normalized(&self) -> u32 { self.page.max(1) }
    pub fn offset(&self, page_size: u32) -> u32 {
        self.normalized().saturating_sub(1) * page_size
    }
}
```

### handlers::posts::list 変更 🔵
```rust
pub async fn list(
    State(state): State<AppState>,
    Query(q): Query<PaginationQuery>,
) -> AppResult<impl IntoResponse> {
    let page = q.normalized();
    let page_size = state.config.page_size;
    let offset = q.offset(page_size);
    let posts = post_repo::list(&state.db, page_size, offset).await?;
    let total = post_repo::count(&state.db).await?;
    let total_pages = ((total + page_size - 1) / page_size).max(1);
    Ok(IndexTemplate { posts, page, total_pages })
}
```

### templates/index.html 追加 🔵
```html
{% if total_pages > 1 %}
<nav aria-label="pagination">
  <ul class="pagination">
    {% if page > 1 %}
    <li class="page-item"><a class="page-link" href="?page={{ page - 1 }}">前へ</a></li>
    {% endif %}
    <li class="page-item active"><span class="page-link">{{ page }} / {{ total_pages }}</span></li>
    {% if page < total_pages %}
    <li class="page-item"><a class="page-link" href="?page={{ page + 1 }}">次へ</a></li>
    {% endif %}
  </ul>
</nav>
{% endif %}
```

### 不正値の扱い 🔵
- `?page=-1` のような負数は u32 のデシリアライズ自体が失敗するため、`Query<PaginationQuery>` ではなく `Query<Option<PaginationQuery>>` を取って `Option::unwrap_or_default()` するか、ハンドラ側で `Result::unwrap_or` する
- もしくは axum の `Query` 取得失敗を Layer で握り、1 にフォールバックするミドルウェアを書いてもよい 🟡
